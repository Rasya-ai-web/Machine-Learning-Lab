# Student Performance Data Preprocessing

## Objective

To preprocess the student performance dataset by performing:

1. Data loading and understanding
2. Missing value handling
3. Duplicate data checking
4. Categorical data encoding
5. Feature scaling
6. Train-test splitting
7. Final dataset verification

## Dataset

The dataset contains student academic and demographic information.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Preprocessing Techniques

- Median imputation for numerical missing values
- Mode imputation for categorical missing values
- Label Encoding
- Duplicate removal
- StandardScaler
- Train-test split

## Target Variable

`FinalGrade`

## Files

- `student_performance_preprocessing.ipynb` — Complete preprocessing code
- `student_performance_updated_1000(1).csv` — Dataset
